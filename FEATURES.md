# CV Master PRO - Features Documentation

## Core Features

### 1. 🎯 AI-Powered CV Tailoring

**What It Does**
- Analyzes your CV and target job description
- Rewrites CV to match job requirements
- Generates a fitness score (0-100%)
- Identifies gaps and missing qualifications

**How to Use**
1. Paste your CV in "Source CV Data" section
2. Paste job description in "Target Job Profile"
3. Click "Rewrite My CV & Score Fit"
4. Review the optimized CV and fit score
5. Make manual adjustments using the floating menu

**Key Features**
- One-page formatting enforcement
- Smart bolding for emphasis (company names, titles)
- Quantified achievements preference
- Professional markdown formatting

**Perfect For**
- Job seekers optimizing for specific roles
- Finance professionals applying to IB roles
- Candidates wanting to customize per application

---

### 2. 📄 Cover Letter Generation

**What It Does**
- Creates context-aware cover letters
- Matches tone to job description
- Integrates your CV highlights
- Formats in professional markdown

**How to Use**
1. Ensure you have an optimized CV
2. Click "Cover Letter" tab
3. Click "Draft Cover Letter" button
4. Review and edit as needed
5. Export as DOCX

**Features**
- 350-word limit (professional standard)
- Automatic integration with CV content
- Recruiter-friendly formatting

**Perfect For**
- Saving time on cover letter writing
- Ensuring consistency with CV
- Quick draft generation before manual polish

---

### 3. 🚀 Portfolio Strategy Guide

**What It Does**
- Analyzes your background vs target role
- Recommends portfolio projects
- Suggests bridge strategies
- Categorizes projects by tier

**Tier System**
- **Tier 1**: Direct Skill Match (highest relevance)
- **Tier 2**: Transferable Skills (bridge strategies)
- **Tier 3**: Prestige Signals (brand building)

**How to Use**
1. Input your CV and target job
2. Click the lightbulb icon
3. Review recommended projects
4. Prioritize tier 1 projects
5. Use bridges to contextualize tier 2/3

**Perfect For**
- Career changers needing skill bridges
- Finance candidates building prestige
- Strategic project planning

---

### 4. ✏️ Intelligent Text Editing

**Floating Menu (Select Text in Preview)**

When you select any text in the CV preview, a floating menu appears with three modes:

#### Edit Mode
- Provide editing instructions
- AI rewrites selected text
- Examples:
  - "Quantify this achievement"
  - "Make it more leadership-focused"
  - "Highlight technical skills"

#### Ask Mode
- Ask questions like a recruiter would
- Get insider perspectives
- Examples:
  - "Would this impress a hedge fund?"
  - "Is this bullet point strong enough?"
  - "How would you improve this?"

#### Emphasize Mode
- Get AI-suggested editing directives
- Smart actionable improvements
- Click a suggestion to apply it
- Examples:
  - "Add specific dollar amounts"
  - "Highlight deal experience"
  - "Show leadership scope"

**Perfect For**
- Fine-tuning individual sections
- Real-time feedback and iteration
- Targeted improvements

### 10. 🔍 Fit Analysis

**What You Get**

- **Fit Score (0-100%)**: How well your CV matches the job
- **Reasons**: Why you're a good fit
- **Missing Elements**: What to improve

**How to Use**
1. Generate optimized CV
2. Look at score circle in preview
3. Read reasons listed
4. Identify missing elements
5. Improve and regenerate

**Interpretation**
- 80%+: Excellent fit
- 60-79%: Good match, some gaps
- 40-59%: Possible with skill bridges
- <40%: Major pivots needed

**Perfect For**
- Assessing application viability
- Identifying skill gaps
- Strategic planning

## Common Questions

**Q: Is my data secure?**
A: Yes. Firebase encrypts data in transit and at rest. Your CV is only stored if you click Save. Anonymous auth prevents unauthorized access.

**Q: Can I edit the Gemini API key?**
A: It's in environment variables. For Vercel deployment, update in project Settings → Environment Variables.

**Q: How many CVs can I save?**
A: Unlimited (Firebase free tier supports 1GB storage, enough for ~10k CVs).

**Q: Can I use this for non-finance roles?**
A: Absolutely! Customize the strategic philosophy for your industry.

**Q: Does it work offline?**
A: No, requires internet for Gemini API calls and Firebase sync.

**Q: Can I share profiles with others?**
A: Not currently, but you can export as DOCX and share.
